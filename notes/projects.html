STM32 OLED GUI

OLED 多级菜单 UI 设计

基于 STM32F103 的 0.96 寸 OLED 屏幕菜单系统。支持多级嵌套菜单、滚动条显示、以及函数指针绑定的交互逻辑。采用 GRAM 缓冲刷新机制，极大提升了 UI 的流畅度。

STM32 FreeRTOS PID

Stm32BalanceCar

基于 STM32C8T6 的平衡车代码设计，使用 CubeMX 配置硬件层，集成 FreeRTOS 实时操作系统实现多任务调度，核心算法采用增量式 PID 控制。

GitHub 源码
树莓派 C语言 智能家居

RaspberryPiSmartHome

树莓派智能家居项目，基于 wiringPi 库使用 C 语言开发。包含温湿度监测、远程灯光控制及监控系统，运行于树莓派 3B+ platform。

STM32F103 NRF24L01 2.4G

Stm32RemoteControl

通用的 2.4G 无线遥控器，基于 STM32F103CBT6。使用 NRF24L01 进行远距离低延迟通信，同样采用了 FreeRTOS 框架。

GitHub 源码
