配置 FreeRTOS 任务和队列

注意：gpio_isr_handler 中断回调函数加载在 IRAM_ATTR 中，不能执行 printf 等耗时操作。

void gpio_intr_init(void)
{
    gpio_install_isr_service(ESP_INTR_FLAG_LEVEL1);
    gpio_isr_handler_add(GPIO_NUM_3, gpio_isr_handler, (void*) GPIO_NUM_3);
    gpio_evt_queue = xQueueCreate(10, sizeof(uint32_t));
}
中断任务处理
static void IRAM_ATTR gpio_isr_handler(void* arg)
{
    uint32_t gpio_num = (uint32_t) arg;
    xQueueSendFromISR(gpio_evt_queue, &gpio_num, NULL);
}

ESP32 常见问题

仅输入引脚 (GPIO 34-39)

这些引脚没有内部上拉或下拉电阻，不能用作输出。

  • GPIO 34 / GPIO 35 / GPIO 36
  • GPIO 37 / GPIO 38 / GPIO 39

集成 SPI 闪存引脚 (GPIO 6-11)

这些引脚连接到 ESP-WROOM-32 芯片上的集成 SPI 闪存，不建议用于其他用途。

  • GPIO 6 (SCK/CLK) / GPIO 7 (SDO/SD0)
  • GPIO 8 (SDI/SD1) / GPIO 9 (SHD/SD2)
  • GPIO 10 (SWP/SD3) / GPIO 11 (CSC/CMD)

电容式触摸 GPIO

ESP32 有 10 个内部电容式触摸传感器，可检测手指触摸并用于唤醒深度睡眠。

  • T0 (GPIO 4) / T1 (GPIO 0) / T2 (GPIO 2)
  • T3 (GPIO 15) / T4 (GPIO 13) / T5 (GPIO 12)
  • T6 (GPIO 14) / T7 (GPIO 27)
  • T8 (GPIO 33) / T9 (GPIO 32)

ESP8266 AT 指令使用

基础 AT 指令

AT                      // 测试
AT+CWMODE?              // 查看模式 Station/SoftAP/Station+SoftAP
AT+CWMODE=1             // 设置为 Station
AT+CWLAP                // 列出周围 WiFi
AT+CWJAP="SSID","PASS"  // 连接到 WiFi
AT+CIPSTA?              // 查看本机 IP
AT+CWQAP                // 断开 WiFi 连接

TCP 透传连接

AT+CIPMUX?              // 查询传输模式
AT+CIPMODE=1            // 设置成透传
AT+CIPSTART="TCP","192.168.137.123",8888  // TCP 连接
AT+CIPSEND              // 进入透传
+++                     // 退出透传 (不发送新行)
